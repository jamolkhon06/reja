# 📋 Reja

A simple task and planning web application built with **Node.js, Express.js, EJS, HTML, CSS, and JavaScript**.

The project was developed as a practice project for learning backend development, server-side rendering, working with JSON data, routing, and connecting frontend views with backend logic.

---

## 🚀 Features

- 📝 Create and manage tasks/plans
- 👤 Author/user information
- 📄 Server-side rendered pages using EJS
- 💾 JSON-based data storage
- 🎨 Custom CSS styling
- ⚡ Express.js backend
- 🔄 Dynamic data rendering
- 🧪 JavaScript practice and algorithm tasks
